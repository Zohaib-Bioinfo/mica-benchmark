\section{Reproducibility and statement on assistance}\label{sec:repro}
\paragraph{Repository.} \url{\RepoURL} holds the specification (\texttt{docs/SPEC.md}) and the project log with every decision, error and change (\texttt{LOG.md}); the frozen entry list and the selection record (\texttt{data/}); the notebooks as run, their generators and the analysis scripts with their tests (\texttt{scripts/}); the environment files (\texttt{env/}) and the pinned methods table (\texttt{methods/}); the unpacked text outputs of every session and the scores of every model (\texttt{results/raw/}); and this report (\texttt{report/}).
\paragraph{Regenerating the report.} One script turns the scores and the status tables into the statistics (\texttt{analyze\_results.py}), one draws the figures (\texttt{make\_figures.py}), one writes the tables and the numbers of the text (\texttt{make\_report\_tables.py}) and one compiles the PDF (\texttt{build\_report.py}), which stops if a number, a reference or a citation is missing. The commands are in the \texttt{README.md}.
\paragraph{What is not in the repository.} The AF3 predictions (the terms of AlphaFold Server), the Phenix installer and the coordinate files of the models; the AF3 job list, the checks and the file hashes are public, so that the inputs can be recreated. Running the notebooks again needs a Kaggle account with GPU quota, the private AF3 dataset and a Phenix download login.
\paragraph{Statement on AI assistance.} I set the task, the scope and the locked specification (\texttt{docs/SPEC.md}), ran every notebook on my own Kaggle account, made the AF3 predictions, supplied the Phenix licence and decided what to do when a run failed. The scripts, the notebooks, the tests, the project log and the text of this report were written by an AI assistant (Claude, Anthropic), working from the specification and my instructions and reading the session outputs that I uploaded; every number of the report is computed by a script of the repository from those outputs. I am responsible for what the report says. The assistant's own mistakes, such as a Phenix parameter in the second docking pass that this Phenix version rejected, are recorded in \texttt{LOG.md}.
