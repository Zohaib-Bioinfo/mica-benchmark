\section{Reproducibility and statement on assistance}\label{sec:repro}
\paragraph{Repository.} \url{\RepoURL} holds the specification (\texttt{docs/SPEC.md}) and the project log with every decision, error and change (\texttt{LOG.md}); the frozen entry list and the selection record (\texttt{data/}); the notebooks as run, their generators and the analysis scripts with their tests (\texttt{scripts/}); the environment files (\texttt{env/}) and the pinned methods table (\texttt{methods/}); the unpacked text outputs of every session and the scores of every model (\texttt{results/raw/}); and this report (\texttt{report/}).
\paragraph{Regenerating the report.} One script turns the scores and the status tables into the statistics (\texttt{analyze\_results.py}), one draws the figures (\texttt{make\_figures.py}), one writes the tables and the numbers of the text (\texttt{make\_report\_tables.py}) and one compiles the PDF (\texttt{build\_report.py}), which stops if a number, a reference or a citation is missing. \texttt{scripts/regenerate.sh} runs the four in order (\texttt{-{}-check}: compare the tables only); see the \texttt{README.md}.
\paragraph{What is not in the repository.} The AF3 predictions (the terms of AlphaFold Server), the Phenix installer and the coordinate files of the models; the AF3 job list, the checks and the file hashes are public, so that the inputs can be recreated. Running the notebooks again needs a Kaggle account with GPU quota, the private AF3 dataset and a Phenix download login.
\paragraph{Statement on AI assistance.} I did this project with an AI assistant, Claude (Anthropic), and the work was divided as follows. \emph{My part:} I took the task from Prof.\ Cheng, chose the free-compute plan and locked the specification (\texttt{docs/SPEC.md}: the methods, the entry filters and the selection rule, the metrics, the statistics and the handling of failed runs) on 10~October 2026, before any method was run; I made the AF3 predictions, obtained the Phenix academic licence, ran every notebook that produced a result on my own Kaggle and Colab accounts, uploaded the outputs of each session and read this report in full. \emph{The assistant's part:} it wrote the notebooks, the scripts and their tests, the project log and the text of this report, working from the specification and from the outputs that I uploaded; it proposed the plan for each stage and the technical decisions, which I approved. \emph{Checks:} every result in the report is computed from the raw outputs by the scripts of the repository and inserted automatically (the few figures quoted from logs are marked as such, Section~\ref{sec:procedure}), and every decision, error and change, including the assistant's own mistakes (for example a Phenix parameter in the second docking pass that this Phenix version rejected), is dated in \texttt{LOG.md}. I am responsible for what this report says.
